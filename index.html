One-time setup (Google Cloud project)

Someone with access to a Google Cloud project needs to do this once:

  1. Go to Google Cloud Console → APIs & Services → Library and enable the Google Drive API and Google Sheets API.
  2. APIs & Services → Credentials → Create Credentials → OAuth client ID. Application type: Web application.
  3. Under Authorized JavaScript origins, add the URL this page is hosted at (e.g. your GitHub Pages URL, just the origin — no trailing path).
  4. If prompted, configure the OAuth consent screen — internal-only if this is a Google Workspace org and you want it restricted to your org.
  5. Copy the Client ID into the field below.

This app requests read access to files in the folder you link, plus permission to create/edit a results Sheet inside that same folder — nothing else in your Drive.

Sync Now reads any new or changed .docx files in the linked folder, extracts indicators from them (tagged with the reporting period set on the Extract tab), and pushes new rows into the results Sheet in that same folder.
